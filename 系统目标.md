# Ultra Low Latency GPU Video Pipeline

## DPDK + GPUDirect RDMA + NVDEC + EGL/DRM

---

# 1. 系统目标

构建一套：

- 超低延迟
- 零拷贝
- NUMA-aware
- GPU-native
- kernel bypass
- 可横向扩展

的视频接收/解码/显示系统。

目标延迟：


| 模块                | 目标      |
| ----------------- | ------- |
| NIC RX            | < 5 us  |
| RTP depacketize   | < 50 us |
| NVDEC decode      | 1~3 ms  |
| Render/display    | 1~5 ms  |
| 总体 Glass-to-Glass | 5~15 ms |

# 4. 系统核心原则

## 4.1 全链路零拷贝

禁止：

```text
NIC → Kernel → Userspace → CPU memcpy → GPU
```

目标：

```text
NIC DMA → GPU memory
```

---

## 4.2 用户态网络

使用 DPDK PMD：

- 无中断
- poll mode
- lock-free queue
- batch RX/TX

---

## 4.3 GPU Native Pipeline

解码后：

禁止：

```text
GPU → CPU → GPU
```

必须：

```text
NVDEC → CUDA Surface → EGL/Vulkan
```

---

## 4.4 NUMA Awareness

NIC 与 GPU 必须：

- 同 NUMA
- 同 PCIe root complex

否则：

PCIe latency 将急剧上升。

---

# 5. 核心模块设计

---

# 5.1 DPDK RX Engine

职责：

- NIC RX queue
- burst receive
- flow steering
- RSS
- packet timestamp

关键：

```cpp
rte_eth_rx_burst()
```

优化：

- 64 packet burst
- cache prefetch
- lockless ring

---

# 5.2 RTP Engine

职责：

- RTP reorder
- packet loss detect
- jitter buffer
- FU-A/STAP-A

输入：

```text
UDP RTP packet
```

输出：

```text
完整 H264 AnnexB NALU
```

---

# 5.3 H264/H265 Parser

负责：

- NALU 拼接
- AnnexB start code
- SPS/PPS 提取
- IDR 检测

输出：

```text
NVDEC consumable bitstream
```

---

# 5.4 GPUDirect RDMA Layer

目标：

```text
NIC DMA -> GPU VRAM
```

需要：

- Mellanox OFED
- nvidia-peermem
- IOMMU passthrough

关键：

```text
ibv_reg_mr()
cudaHostRegister()
```

---

# 5.5 NVDEC Engine

接口：

```cpp
cuvidCreateDecoder()
cuvidDecodePicture()
```

输出：

```text
CUDA surface
```

支持：

- H264
- H265
- AV1

---

# 5.6 Render Engine

方案：

## 推荐：

EGL + DRM/KMS

避免：

- X11
- Wayland compositor
- Qt

原因：

减少 display latency。

---

# 5.7 Display Engine

直接：

```text
DRM Atomic Commit
```

实现：

- vsync sync
- page flip
- low jitter

---

# 6. 内存模型

---

# 6.1 HugePage

DPDK mbuf：

```text
2MB hugepage
```

避免：

TLB miss。

---

# 6.2 CUDA Pinned Memory

使用：

```cpp
cudaHostAlloc()
```

避免 pageable memory。

---

# 6.3 Zero Copy Ring

使用：

```text
SPSC lock-free ring
```

禁止：

- mutex
- malloc/free
- shared_ptr

---

# 7. 多线程模型

```text
Core0:
    RX Poller

Core2:
    H264 parser

    Display submit
```

原则：

- 一核一职责
- CPU isolation
- no migration

# 9. 风险点


| 风险              | 说明              |
| --------------- | --------------- |
| RTP reorder     | 最容易出错           |
| GPU sync        | 难调              |
| PCIe topology   | 性能关键            |
| NUMA mismatch   | latency 暴涨      |
| Display tearing | 需要 frame pacing |
